# 3D-Public-Lab
This is a project for building a much versatile and comprehendible script library for making 3D with the upcoming GM3D in Game Maker Studio

## Can I use this?
Yes you can! Whatever resource that is provided is free to use! Please note that this is experimental and is constantly changing as the GM3D resource is on its early development phase.

## Can I edit this project?
Yes! This is a public access project for the community. You are free to edit this project by providing your own scripts and other resources that will help with the 3D development for all of us. Whatever format that suits you best for others to try out! 

## IMPORTANT!
The GM3D resources are based from the sample file provided by iampremo & kraifpatrik, found here: https://github.com/YoYoGames/GM3D-Samples
It is still under development and may change in the future.

## Lastly...
Please make sure your own assets are set in its own separate GROUP folder to keep the project tidy! Thank you!
